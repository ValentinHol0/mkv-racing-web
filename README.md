## 📌 Огляд проєкту

**MKV Racing** — це спеціалізована веб-платформа та супутній серверний хаб, розроблений для поціновувачів реалістичного автосимулятора **Assetto Corsa** (локації *Shuto Revival Project* та *Georgia Tbilisi*). 

Платформа вирішує ключову проблему симрейсингу: усуває складність ручного пошуку серверів та синхронізації модифікацій завдяки:
- 🚀 **Однокліковому підключенню** через браузерний протокол `acmanager://`.
- 🔍 **Автоматичній валідації хеш-сум модів (SHA-256)**, що виключає помилки `Checksum Mismatch`.
- 📡 **Живій телеметрії в реальному часі** (WebSocket радар трафіку, погода Pure 3.10, пінг, стан слотів).
- 🏎️ **3D-гаражу болідів** із селектором фірмових ліврей та технічними паспортами (Toyota Supra MKV, Audi R8 V10, Porsche 911 GT3 RS, BMW M5 CS тощо).
- 🔐 **Автентифікації пілотів** через **Steam OpenID 2.0 SSO** (підтвердження SteamID64 та ліцензійних DLC) або внутрішній токен водія.

## 🎨 Дизайн-система та інтерфейсні сторінки

Дизайн розроблено у середовищі **Figma** відповідно до концепції **Dark Racing UI**:
- **Основні кольори:** Deep Cyber Slate (`#12161E`), Dark Cobalt Surface (`#181D26`), Crimson Racing Red (`#E63946`), Emerald Telemetry (`#10B981`), Cyan Glow (`#06B6D4`).
- **Шрифти:** `Inter` (інтерфейсні тексти), `Rajdhani` (спортивні показники, швидкість, потужність), `JetBrains Mono` (телеметрія, консольні логи).

### 🖥️ Представлені сторінки веб-застосунку:
1. **Головна панель (Dashboard):** Картки серверів, віджет погоди Shuto Weather, живий міні-радар траси, графіки навантаження, лідерборд.
2. **Серверна інфраструктура (Servers):** Каталог кластерів, фільтрація за регіонами (Japan/Georgia), параметри мережевого баббла (300 м), tick rate (40/30 Hz).
3. **Віртуальний 3D-гараж (Garage):** Виставковий бокс, селектор болідів, технічні характеристики (HP, Nm, 0-100), перевірка цілісності модифікацій.
4. **Аналітика та телеметрія (Statistics):** KPI сесій, секторний таймінг Shuto C1, графіки швидкості кола та бічного прискорення (Lateral G).
5. **Особистий кабінет пілота (Profile):** Driver Level 42 Pro Tier, рейтинги надійності (Safety 98.4%, Pace 94.2), пробіг автопарку, нагороди.
6. **Консоль системних логів (Logs):** Пряма трансляція подій ядра сервера, рівні логів Info/Warn/Checksum, ресурси сервера (CPU 18.2%, RAM 12.6/32 GB).
7. **Модуль авторизації (Auth Modal):** Автентифікація через Steam OpenID SSO з верифікацією DLC або за внутрішнім токеном водія.

Всі графічні макети доступні у директорії [`assets/mockups/`](./assets/mockups/).

## 🛠️ Запланований стек реалізації (до кінця семестру на React)

- **Frontend:** React 18, Vite 5, Tailwind CSS v3, React Router v6.
- **State Management:** Zustand / React Context API.
- **Icons & Graphics:** Lucide React, Three.js / Canvas (для 3D-моделей авто), Recharts (для телеметрії).
- **Networking:** WebSocket Client + REST API.
